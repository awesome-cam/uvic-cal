Quick Tips

  • Use OR groups for alternative course choices.
  • Pick-X allows selecting multiple courses from a group.
  • Face-to-face mode excludes online lecture sections.
  • Online-only mode excludes face-to-face lecture sections.
  • Courses with TBA or async lecture times are intentionally excluded because they cannot be meaningfully placed into a timetable.
  • Schedule personality changes how schedules are ranked.
  • Semester balancing prefers schedules distributed more evenly between semesters.

Important Reminder

This tool does not verify:

  • prerequisites
  • program restrictions
  • registration eligibility
  • waitlists
  • seat availability

Always confirm your final schedule using the official UVic registration system before registering.
